Lease renewal

A heartbeat extends a live lease owned by the same acquisition token. It never resurrects an expired lease.

Guarded update

PartRule
OwnershipOwnerID = :owner
ValidityExpiresAt > :now
ExtensionExpiresAt = :now + lease_duration
TimingHeartbeat period comfortably below lease duration

Result handling

ResultMeaningAction
Update succeedsLease extendedContinue protected work
Condition failsNot owned or no longer validStop protected work
Other AWS errorRenewal not confirmedHandle before the deadline; never assume success

Heartbeats reduce exposure; they do not provide fencing. A process pause stops the heartbeat but not the passage of time. Once the lease expires, another caller can acquire while the paused holder still has unfinished work.

AWS’s example pairs a 10-second lease with a 3-second heartbeat. Treat this as an example configuration, then choose and test values for your own latency, pause, and clock-skew budget.
